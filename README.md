# 🚀 Full-Stack YOLO Object Detection Application

An end-to-end computer vision solution that integrates a custom-trained **YOLO** model into a web application. This repository contains the complete pipeline, from model experimentation to API deployment and frontend UI.

---

## 🌟 Key Features

* **🧠 Model Training & Analysis:** Jupyter Notebooks covering dataset pre-processing, YOLO training, validation, and inference metrics.
* **⚡ High-Performance Backend:** RESTful API designed to receive image/video data, execute model inference, and return annotated predictions.
* **💻 Interactive Frontend:** User-friendly Web UI for uploading media, tweaking detection thresholds, and viewing results in real time.
* **🔄 Modular Architecture:** Clean separation between model logic, backend services, and client presentation.

---

## 🏗️ Repository Structure

* `notebooks/` - Training, evaluation, and data preparation scripts.
* `backend/` - API server, detection logic, and model loader.
* `frontend/` - Client interface for uploading media and rendering detections.
